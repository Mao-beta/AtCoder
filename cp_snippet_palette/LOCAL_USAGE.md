# このPCでの使い方

使い方・API表示の確認日: 2026-10-19。場所は `D:\Kyopro\AtCoder\cp_snippet_palette`。

## まず使う

1. このフォルダの `run_palette.bat` をダブルクリックする。
2. 検索欄に `UnionFind` と入力する。
3. 種別が **File**、名前が **UnionFind** の行を選び、右側の使い方を読む。コードはF2か「コード」タブで確認できる。
4. **Enter**を押すとコードをコピーする。画面は開いたままになる。
5. PyCharmの解答ファイルで、`main()`の外側・上の方に**Ctrl+V**で貼り付ける。

貼り付けたクラスは、たとえば次のように使う。

```python
uf = dsu(5)
uf.merge(0, 2)
print(uf.same(0, 2))  # True
print(uf.size(0))     # 2
```

`UnionFind.py`のクラス名は指定先に合わせた`dsu`。スニペットは提出コードに貼るためのもの。`pip install`や`import snippets`は不要。

複数のライブラリを探すときも**Enter**でコピーし、PyCharmに貼り付けてからパレットへ戻る。**Ctrl+L**で検索語を入れ替えられる。よく使うものは**Ctrl+D**でお気に入りに登録しておく。

## メイン画面の見方

左側に検索欄、File／Live・分野・表示範囲の絞り込み、その下に候補一覧を置いた。候補は名前と用途の2行で表示し、幅に収まらない部分は省略する。全文は右側で読める。検索欄と候補一覧は↑↓で行き来できる。

右側の上部で種類・名前・用途を確認し、「使い方・解説・API」と「コード」のタブで内容を読む。起動直後は使い方を表示する。コピーは右下の大きなボタンから行い、ボタンの上に貼り付け・展開方法、下に成功・失敗の結果を表示する。Fileはコード全体、Liveは略語をコピーする。

目的ナビと同じ余白・配色・見出しを使い、選択中の候補とキーボードフォーカスを色や枠で示す。左右の境界はドラッグで調整できる。文字サイズの変更は候補一覧にも反映する。Tabでボタンへ移動した場合、Enterはそのボタンの操作になる。検索欄・候補一覧でのEnterは従来どおりコピーする。

## FileとLiveの違い

- **File**: EnterでPythonコードそのものをコピーする。
- **Live**: EnterでPyCharmのテンプレート略語をコピーする。PyCharmでCtrl+Vの後、設定された展開キー（通常Tab）を押す。`$END$`等の変数はPyCharmが処理する。
- **Enter・Ctrl+EnterはFile／Live共通のコピー操作**。コピー後も画面は開いたままになる。
- プレビューの一部だけを選択してCtrl+Cでコピーすることもできる。ただし、Fileの標準操作は必要なimport・補助定義を含むファイル全体のコピー。

コンテストモードと来歴によるコピー制限は削除した。由来・URLの有無にかかわらずコピーでき、コピー時にURLコメントを自動追加することもない。

## プレビューと使い方・解説・API・verifyを使う

「コード」タブは構文を色分けし、行番号と検索語の位置を表示する。「定義へ」の一覧からクラス・メソッド・関数へ直接移動できる。特定のAPI名で検索したときは、コード内のその定義へ自動で移動する。

最初は「使い方・解説・API」を表示する。**F2**でコードと切り替える。Fileを選んだ場合は、そのファイルを貼った後に使える短い実行例から読める。全92ファイルに通常のPythonコードの例を用意した。期待する戻り値は`# => 値`のコメントに記載している。画面に結果を出したい場合は、その式を`print(...)`で囲む。

使用例の次に「アルゴリズムの解説」がある。青レベルを想定し、発想・不変条件・計算量・落とし穴を選択中のFileに絞って表示する。全体を通して読む場合は[アルゴリズム解説](ALGORITHMS.md)を開く。共通の仕組みはまとめ、セグ木などの派生版は更新式の違いも説明している。

見出しは大きな太字と余白で区切り、API定義は青系、入力などの項目名は緑系、計算量の`O(...)`は黄・茶系で強調する。コード例は背景を分けた等幅表示で、Pythonのキーワード・数値・コメントにも色を付ける。本文中の太字やコード記法も反映する。別窓で開く逆引きの表は、各項目に「選ぶ条件」などの列名を添えて表示する。

下へ進むと、選択中のファイルに対応する逆引き、ACL形式との対応、verify候補、各クラス・関数・メソッドの引数・戻り値・前提条件が読める。例えば`lazy_segtree`には区間加算・区間和のコールバック定義一式、`hld`には頂点値・辺値の並べ替え、`mo`には集計用コールバックの例を載せている。引数順・順位の基準・戻り値も説明している。

「公開API」では入力の型・データ形式と計算量も読める。クラスを使うときは、まずクラスの説明で構築引数と共通の添字範囲を確認し、その下のメソッドで操作の計算量を確認する。Nは配列長、σは異なる値数など、各説明に記号の定義がある。今回のdocstring更新はF5で読み直せる。

APIをクリックするとコードの該当行へ戻る。問題名をクリックするとブラウザが開く。ここに掲載した問題は検証先の候補で、オンラインでのAC記録ではない。アプリを起動したまま更新した場合は、一度閉じて`run_palette.bat`から起動し直す。

**Ctrl+F**は、選んでいるコードの中を検索する。F3／Shift+F3で次／前へ移動できる。改行を含まない文字列をコード内で選択してからCtrl+Fを押すと、その文字列が検索欄に入る。コード内検索欄のEnterは次の一致へ、Escは検索欄を閉じる操作になる。

コード・解説・別窓のガイドの文字サイズは、それぞれの「−」「＋」または本文上でCtrl+マウスホイールを使って調整する。サイズ設定は共通で、見出しとの大きさの差も保たれる。上部の「ライト」「ダーク」で、開いている解説やガイドもまとめて配色を変更できる。一覧とプレビューの境界はドラッグして幅を調整できる。

今回の書式・拡大縮小の更新は、パレットを閉じて`run_palette.bat`から起動し直すと反映される。F5だけでは画面プログラムは更新されない。

## スニペットの追加

自己完結した`.py`をこのフォルダの`snippets/`以下に置き、F5で再読み込みする。たとえば`snippets/graphs/SCC.py`。必要なimport・補助定義も同じファイルに含め、入力を読むmain処理は含めない。

ファイル冒頭のdocstringに使い方と通常のPythonコードの例を書き、公開関数・クラス・メソッドには引数・戻り値・前提条件を書く。コード例は4スペース下げ、期待する戻り値は`# => 値`と書く。対話コンソールのプロンプトは付けない。冒頭の説明と各定義のdocstringがF2の画面に表示される。説明のためにスニペットを実行することはない。

アルゴリズムの解説は`ALGORITHMS.md`へ追加する。各Fileに一つの`## 見出し`を置き、直下に`対象: [ファイル名.py](library/分野/ファイル名.py)`の行、その下に本文を書く。パスはこのフォルダからの相対パスにする。この行を使ってF2へ該当節だけを表示するので、本文中の小見出しには`###`以下を使う。文書を保存してF5を押すと読み直せる。

目的ナビへ追加する場合は、`LIBRARY_GUIDE.md`の「目的から探す逆引き」の表に行を追加する。「やりたいこと」セルの先頭に、既存行と同じ形式のHTMLコメントで`navigator: 配列・集合 > 区間を集計する > 和・二乗和・積の和`のような分類を付ける。` > `で階層を区切る。目的・APIへの相対リンク・条件・検索語はその表の4列をそのまま使い、GUI用に説明を複製しない。分類を付け忘れた行も「その他」に表示する。更新後はF5。分類網羅のテストでは未分類と同梱Fileへの案内漏れも確認する。

`config.json`の`keywords`に、ファイル名の拡張子を除いた名前をキーとして日本語の検索語を足せる。任意の`descriptions`にも同じキーで一覧の説明文を設定できる。

```json
"SCC": ["強連結成分", "縮約グラフ"]
```

`snippet_dirs`の相対パスはパレットのあるフォルダが基準。現在は`["snippets", "library"]`。リポジトリ直下の別の`snippets/`や解答ファイル全体は検索しない。[抽出済みライブラリの使い方](LIBRARY_GUIDE.md)と[候補との対応表](LIBRARY_CANDIDATES.md)を参照。

幾何5ファイルは各々に必要なPoint等を含む。複数ファイルを貼ると同じ定義が重複する場合がある。最新のAPIは[ACL_API.md](ACL_API.md)と各ファイルのdocstringを参照。segtree(V,OP,E)、lazy_segtree(V,OP,E,MAPPING,COMPOSITION,ID)、fenwick_tree.sum(l,r)を使う。頂点・添字・順位は0始まり。LCATreeはroot=0、WaveletMatrixのselectもk=0が最初の出現。LinkedListの実ノードIDは0から、先頭挿入はinsert_after(-1,x)。直下の`_cp_structures_guide.md`は旧APIの説明。
